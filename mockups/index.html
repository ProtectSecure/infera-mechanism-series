Four ways to render navigable uncertainty.

Four standalone prototypes of how Competing Explanations could feel. Each uses the same Eviction story hypotheses as test content so you can compare apples to apples. Pick the one that lands and I'll build it across all five stories — or describe the hybrid you want.

Direction 01

Fog of Interpretation

The screen begins blurred and ambiguous. The reader's cursor is a lens — wherever you look, narratives sharpen. Stop looking and they dissolve back. Multiple readings overlap as semi-transparent layers. Some agree; some conflict. Truth is something you have to actively reveal.

Feel: ambiguity · narrative bias · interpretive labor
Open the prototype
Direction 02

Split-Reality Simulation

The screen divides into four panes — Economic, Political, Media, Cultural. Same event read four ways at once. Different vocabulary, different highlighted causal chains, different tone. Hover any pane to expand it. The literacy moment: frameworks shape conclusions.

Feel: media literacy · framing exposure · simultaneity
Open the prototype
Direction 03

County Intelligence Board

TV-news election console feel. Georgia map on the right, pressure overlays + narrative toggles on the left. Click an interpretation and the map repaints — different counties light up under different lenses. Floating data panel updates live. Kornacki-grade.

Feel: broadcast journalism · live analysis · geographic intelligence
Open the prototype
Direction 04

The Machine Room

Industrial interior. Pipes carry money and people. Valves carry pressure. Gauges read voter mood. Each hypothesis reconfigures the plumbing — same machine, different theory of what's connected to what. Mechanism-as-mechanism.

Feel: systems machinery · infrastructure · physical causality
Open the prototype
★ HYBRID · directions 02 + 03

The Lens Console

Split-Reality's literacy point — same fact, four lenses — fused with the Board's broadcast affordances. Click any lens and the entire console reconfigures: the map repaints, the vocabulary swaps, the causal chain rearranges, the room tints with the lens's color. Frameworks-as-environments, not framework-as-paragraph.

Feel: TV-news literacy · framework-as-environment · live broadcast switching
Open the hybrid

Cross-cutting decisions to make once you've seen them

1. Should hypotheses feel equal or asymmetric? Some directions (Split, Board) treat readings as parallel; others (Fog, Machine) let evidence weight pull some forward. 2. Should the user labor for clarity or be given it? Fog requires looking; Split presents everything. 3. Does the interface read editorial or operational? Board feels like a newsroom workstation; Fog feels like a meditation; Machine feels like an engineer's diagram. 4. Hybrid combinations are real options — e.g., Fog-on-Hero + Board-in-the-stage, or Split-as-Pattern + Machine-as-Detail.
